# Practice Software Testing API — QA Portfolio

Projeto de testes de API desenvolvido com foco em Quality Assurance e Software Testing.

## Objetivo

Construir uma suíte profissional de testes para a API do Practice Software Testing, explorando conceitos de:

- API Testing
- REST
- HTTP
- JSON
- Autenticação
- Autorização
- Status Codes
- Headers
- Assertions
- Testes positivos e negativos
- Testes de contrato
- Chaining
- Persistência
- Testes de integração
- Testes de regressão
- Test Data
- Newman
- Git
- GitHub
- GitHub Actions

## API

Practice Software Testing API

Base URL:

https://api.practicesoftwaretesting.com

Documentação:

https://api.practicesoftwaretesting.com/docs?api-docs

OpenAPI:

https://api.practicesoftwaretesting.com/docs?api-docs.json
